⚔️ xlsx-streamer vs SXSSF (Apache POI)
---
🧩 xlsx-streamer (com.monitorjbl:xlsx-streamer)   

  Primary purpose	Reading large .xlsx files efficiently    

 🧰 SXSSF (Apache POI Streaming API)
 
   Writing large .xlsx files efficiently
    
# Summary

🟢 xlsx-streamer → For reading big Excel files (low memory)

🟢 SXSSF → For writing big Excel files (low memory)

🟡 Both are Apache 2.0 open-source and complementary (not competitors).
